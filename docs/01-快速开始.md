# 01 · 快速开始

## 1. 环境

- Ubuntu 24.04（目标机为 10.2.102.143）
- Python 3.12
- 建议 4 核 / 8G 以上
- 需要 sudo（nftables、nginx、systemd）
- 运行时依赖只有 `packaging`；TUI 额外依赖 `textual`

## 2. 安装

```bash
sudo apt-get update
sudo apt-get install -y suricata nginx libnginx-mod-http-modsecurity modsecurity-crs \
  nftables logrotate apache2-utils nmap nikto hydra sqlmap hping3 tcpdump
```

代码放到 `/home/li/nightwatch` 后：

```bash
cd ~/nightwatch
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/pip install -r requirements-tui.txt      # 可选，TUI
```

## 3. 生成配置

```bash
sudo python3 scripts/patch_suricata.py             # HOME_NET / pcap 双接口
sudo install -m 644 deploy/suricata/local.rules /var/lib/suricata/rules/local.rules
sudo install -m 755 deploy/nw-fw /usr/local/sbin/nw-fw
sudo install -m 755 deploy/nw-waf /usr/local/sbin/nw-waf
sudo install -m 644 deploy/fw-allow /etc/nightwatch/fw-allow
sudo install -m 440 deploy/sudoers.d/nightwatch /etc/sudoers.d/nightwatch
sudo visudo -c
```

然后：

```bash
bash scripts/deploy.sh
```

它会装 systemd unit、nginx 配置、logrotate、nft 表，重启服务并执行 `./nightwatch status`。

## 4. 配置模型密钥（可选，AI 用）

```bash
cd ~/nightwatch
umask 077
printf 'DEEPSEEK_API_KEY=%s\n' '<你的 Key>' > data/agent.env
sudo systemctl restart nightwatch
```

检查：

```bash
./nightwatch info
```

期望 `key_present: true`、`autonomy: auto`、`autopilot: true`。

## 5. 第一条命令

```bash
./nightwatch status
./nightwatch events --limit 10
./nightwatch bans
./nightwatch chain
```

## 6. 实时看攻击

```bash
# 终端 A
cd ~/nightwatch
./nightwatch battle --tui

# 终端 B（Kali 或本机）
sqlmap -u "http://10.2.102.143:8081/lab/item?id=1" --batch
sudo hping3 -S -c 2000 -i u2000 -p 8081 10.2.102.143
curl http://10.2.102.143:8081/admin
```

TUI 左栏出现攻击，右栏出现 AI 工具调用与结论，底部是记分牌。

## 7. 演示前重置

```bash
bash scripts/demo_reset.sh
```

解封全部、清 nft、清 AI WAF 规则、暂停 daemon autopilot。

## 8. 停止/重启

```bash
sudo systemctl status nightwatch
sudo systemctl restart nightwatch
sudo journalctl -u nightwatch -f
```

## 9. 目录

```
nightwatch
├── app/            # 核心：config/store/worker/detect/decide/enforce/fw/parsers
├── agent/          # AI：tools/runner/prompt/autopilot
├── battle/         # Battle Agent / TUI / plain
├── verify/         # OSV 依赖验真 / 资产探测
├── demo/           # 演示站 / 假 SSH / 模拟器
├── deploy/         # systemd / nginx / nftables / wrapper / sudoers
├── scripts/        # 部署 / 自检 / 红队 / 演示
├── tests/          # pytest
└── docs/           # 本目录
```

## 一句话

你从 Kali 发起攻击，服务器上的确定性引擎负责检测和封禁，AI Agent 负责调查、解释、补处置；
终端 `battle --tui` 左右分屏实时显示「攻击 → 检测 → 工具调用 → 封禁 → 证据」。
